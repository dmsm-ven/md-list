# Основные моменты для нового WPF Desktop App (C#)

## Стек / архитектура
* Версия .NET 10
* DependencyInjection с самого старта Microsoft.Extensions.Hosting.IHost (версия не ниже 10.0.13)
* База данный sqlite
* ORM Dapper
* MVVM TOOLKIT (версии не ниже 8.4.2) - использовать mvvm по умолчанию
* WPF-UI (версии не ниже 4.3.0) - т.е. все элементы UI стараться использовать из этой библиотекки, в том числе иконки для кнопок
* Использовать slnx формат Solution по умолчанию
* Использовать Directory.Build.props и Directory.Packages.props по умолчанию
* При добавлении nuget package проверять на nuget.org что эта последняя версия
* Предпочтение сохранять пользовательские данные (db, json, settings файлы и т.д.) в AppData\Roaming папке вместо exe dir

## Структура проекта
* Models/       # Бизнес-модели и сущности данных
* ViewModels/   # Логика представления (MVVM)
* Views/        # Окна и пользовательские элементы (XAML)
* Services/     # Сервисы (работа с БД, файлами, API)
* App.xaml      # Точка входа приложения

## Минимальный функционал
* Всегда создавать mutex для единичного инстанса приложения
* Всегда предлогать указать png/jpg/ico файл иконки приложения
* Всегда создавать на главной форме возможность открытия окна настроек (SettingsWindow) с следующим функционалом
1.Выбора темы приложения  
2.Возможностью указать Background image которое будет на фоне всех окон приложения
В том числе для Background image нужно 4 опции:
- прозрачность подложки (overlay slider 0-100%, step 1%)
- цвет подложки (RGB HEX / color picker)
- замостить изображения (для мелких бесшовных текстур)
- масштаб бесшовной текстуры (slider 5-150%, step 5%, активен только при отметки пункта *Замостить изображение*)
