# Основные моменты для нового WPF Desktop App (C#)

## 🧱 Стек и архитектура
- .NET 10.
- Dependency Injection с самого начала через `Microsoft.Extensions.Hosting.IHost`.
- SQLite для локальной БД, Dapper для доступа к данным.
- CommunityToolkit.Mvvm — использовать MVVM по умолчанию.
- WPF-UI — использовать компоненты и иконки библиотеки, если они подходят для задачи.
- Использовать формат Solution `.slnx`.
- Использовать `Directory.Build.props` и `Directory.Packages.props` (Central Package Management).
- Использовать короткую форму namespace (File-Scoped Namespaces)
- При обращении к статическому классу File или Directory проверять что бы был добавлен namespace System.IO

## 📁 Структура проекта
- `Models/` — бизнес-модели и сущности данных.
- `ViewModels/` — состояние и логика представления.
- `Views/` — окна и пользовательские элементы XAML.
- `Services/` — прикладные сервисы, работа с файлами и внешними API.
- `Data/` — доступ к БД, SQL-запросы и миграции.
- `Resources/` — стили, шаблоны и ресурсы приложения.
- `App.xaml` — ресурсы и точка входа приложения.

## ⚙️ Базовый функционал
- По умолчанию обеспечивать один экземпляр приложения через именованный `Mutex`; корректно освобождать его при завершении.
- Предусматривать возможность указать иконку приложения: `.ico` для значка Windows
- На главном окне предусматривать доступ к `SettingsWindow`.

## 🎨 Настройки и оформление
- Предусмотреть выбор светлой, тёмной и системной темы.
- Предусмотреть возможность выбрать фоновое изображение для окон приложения.
- Для фонового изображения добавить:
  - Прозрачность подложки: slider 0–100%, шаг 1%.
  - Цвет подложки: HEX/RGB и Color Picker.
  - Замощение изображения для мелких бесшовных текстур.
  - Масштаб текстуры: 5–150%, шаг 5%; активен только при включённом замощении.
- Сохранять настройки и выбранные пользователем пути между запусками.

## 💾 Данные и хранение
- Не хранить пользовательские данные рядом с EXE.
- Использовать `%AppData%\Roaming` для пользовательских настроек, а `%LocalAppData%` — для кэша, логов и локальных данных, которым не нужна синхронизация.
- Использовать параметризованные SQL-запросы

## 🧭 Общие правила
- Если у новой функции есть несколько разумных вариантов реализации, кратко сравнивать их и предлагать выбор.
- Не добавлять NuGet-пакеты без реальной необходимости. Перед добавлением NuGet-пакетов проверять актуальную стабильную версию, совместимость и статус поддержки на NuGet.org.
